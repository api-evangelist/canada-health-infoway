# Canada Health Infoway — Terminology Gateway

> Canada Health Infoway is an independent, federally funded not-for-profit that leads pan-Canadian digital-health interoperability. Its developer surface is the national Terminology Gateway: a HL7 FHIR R4 (4.0.1) terminology service plus a companion RESTful terminology API for browsing and downloading Canadian code systems, value sets (subsets), concept maps, and packages. Terminology content is gated behind free registration + a session/token login; the FHIR CapabilityStatement is served anonymously. Infoway also stewards CA Core+ / CA Baseline, the Canadian FHIR Registry, and the Canadian URI Registry.

## APIs

- [Infoway FHIR Terminology Service API](https://termapi.infoway-inforoute.ca/fhir/fhir-apidocs/v1/swagger-ui): FHIR R4 CodeSystem/ValueSet/ConceptMap with $lookup, $expand, $translate, $validate-code. Base: https://termapi.infoway-inforoute.ca/fhir/v1
- [Infoway Terminology Service API](https://termapi.infoway-inforoute.ca/schema/v1/swaggerui/index.html): RESTful browse/download of code systems, subsets, maps, packages, resource locations, and change notifications. Base: https://termapi.infoway-inforoute.ca/rest/v1

## Auth

- Session/token: Base64 basic credentials, SSO token (ssotoken), or JWT (btoken) via query param or Authorization header.
- Login: POST https://termapi.infoway-inforoute.ca/rest/v1/session
- No OAuth2 / SMART-on-FHIR scopes; no /.well-known/smart-configuration.
